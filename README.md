# Your Feed Knows You Too Well

> An interactive experience that explores how your choices shape your personalized feed.

## 📌 About the Project

**Your Feed Knows You Too Well** is an interactive web project that demonstrates how recommendation systems learn from user preferences and behaviour.

The project allows users to explore their personalized feed profile and then experiment with different algorithmic constraints through the **Constraint Lab**.

Instead of only showing users what their feed looks like, the project lets them interact with the rules behind it.

---

## ✨ Features

- 🎯 Personalized feed analysis
- 🧠 Feed archetype generation
- 🧩 Interactive Constraint Lab
- ⚠️ Constraint conflict detection
- 📊 Feed impact simulation
- 🎲 Discovery / Chaos Budget
- 🧪 Algorithm Stress Test
- 🔄 Algorithm Reboot
- 📱 Interactive and responsive UI

---

## 🧩 Constraint Lab

The Constraint Lab is the main interactive feature added to the project.

Users can experiment with different restrictions and observe how they affect their simulated feed.

It allows users to:

- Add custom constraints
- Detect conflicting preferences
- Simulate changes in the content pool
- Control discovery and predictability
- Run algorithm stress tests
- Reboot the recommendation system

This helps demonstrate how increasing constraints can make a feed more predictable while reducing content discovery.

---

## ⚙️ How It Works

The project follows a rule-based scoring system:

User Preferences  
↓  
Behaviour & Choices  
↓  
Weighted Scoring  
↓  
Feed Archetype  
↓  
Personalized Feed  
↓  
Constraint Engine  
↓  
Modified Feed Behaviour

The JavaScript logic processes user inputs, calculates scores, determines the feed archetype, and applies the selected constraints to simulate their impact.
